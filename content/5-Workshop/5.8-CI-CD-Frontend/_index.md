### Goal

Up to this point, the Back-end API (Serverless) of Smart Campus is operating smoothly. Now is the time to put the User Interface (Front-end) on the Cloud, while establishing a continuous integration and deployment (CI/CD) pipeline for both Frontend and Backend to fully automate the software development lifecycle.

In this chapter we will perform:
1. **CI/CD Automation for Backend with AWS CodePipeline:** Set up an automated flow to build and deploy serverless infrastructure whenever there is new code.
2. **Host a static website on Amazon S3:** Cheap, durable, and requires no server management.
3. **Accelerate with Amazon CloudFront (CDN):** Cache content at Edge Locations globally, helping websites load extremely fast and enhancing security.
4. **Automate CI/CD flow for Frontend with AWS CodePipeline:** Pull code from GitHub, build, and push directly to S3 entirely automatically.
