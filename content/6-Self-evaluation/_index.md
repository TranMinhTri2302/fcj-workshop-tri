## Self-Assessment

During my internship at **FCAJ (First Cloud AI Journey)** from **June 22, 2026** to **August 15, 2026**, I had the opportunity to learn, practice, and apply my programming knowledge in a real-world environment built on AWS cloud technologies.

In addition, I also contributed to tasks such as workflow standardization, architecture diagram updates, frontend integration with backend/AWS services, technical blog writing, and workshop documentation support. ### Reflection on the work completed

Throughout the internship, I directly contributed to building the main user interfaces of the system, including **Users, Attendance, Tasks, Analytics/Dashboard, Leaves, and Login**, while also handling frontend-related features such as **RBAC, Private Route, PermissionGuard, camera/webcam integration, file uploads via S3 Presigned URL, Face Liveness, and frontend deployment on S3 + CloudFront**.

In addition to frontend development, I also supported several tasks that helped connect the technical parts of the project, such as:
- standardizing several business workflows to make development more consistent;
- updating the architecture diagram based on mentor feedback;
- aligning naming conventions, payloads, and responses between frontend and backend;
- writing 3 technical blog posts;
- supporting workshop documentation in areas such as security, database, analytics, monitoring, and testing.

### Areas for improvement

- **Time estimation:** I need to break tasks into smaller parts and define clearer checkpoints to avoid spending too much time on a single complex integration issue.
- **Reading English technical documentation:** I need to improve my speed in reading official AWS documentation so that I can look up information faster and more accurately.
- **Presentation skills:** I need to practice explaining technical issues more clearly, concisely, and directly.

### Conclusion

Overall, I evaluate my internship performance as **good**. The internship at FCAJ significantly improved my technical skills, especially in developing the user interface for a real cloud-based system, working with backend services and AWS integrations, and strengthening my documentation and teamwork skills in a technically demanding environment.

At the same time, this experience also helped me recognize the areas I still need to improve, particularly in technical communication, deeper documentation reading, earlier testing practices, and more accurate time estimation. These are important lessons that I will continue to work on in future projects.
